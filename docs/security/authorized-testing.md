# PHANTOM-X — Authorized Testing Boundaries

## 1. Ethical & Legal Scope

PHANTOM-X is exclusively built for authorized defensive security testing. It must only be targeted against applications where explicit written consent and scope authorization have been granted.

## 2. In-Scope Validation

Before configuring target URLs in the platform:
1. Ensure the domain is registered under the organization's verified domain list.
2. Confirm target environment is designated as `staging`, `development`, or `sandbox`.
3. Never point PHANTOM-X toward third-party production infrastructure without an active penetration testing authorization token.
